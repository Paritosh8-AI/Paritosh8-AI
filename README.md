### 🌟 Featured Systems & Flagship Repositories

#### 1. ⚡ [AgenticEV RCA Studio](https://github.com/Paritosh8-AI/AgenticEV_RCA)
> **Autonomous AI-Driven Root Cause Analysis (RCA) & Causal Inference Engine for EV Fast-Charging Networks**
- **Domain**: Resolves the 18%–25% charging failure rate across distributed EVSE hardware, vehicle BMS contactors, and OCPI roaming protocols.
- **Tech Stack**: `Python` • `FastMCP` • `Playwright` • `FastAPI` • `Pytest` • `Word/Excel Synthesis`
- **Key Highlight**: Uses **FastMCP (Model Context Protocol)** to empower LLM agents with autonomous telemetry diagnosis tools, temporal anomaly detection, and deterministic fault attribution.

#### 2. 🛡️ [UPI Sentinel 2.0](https://github.com/Paritosh8-AI/UPI-Fraud-Detection-System)
> **Enterprise Real-Time AI Fraud Prevention System for Digital Payment Networks**
- **Domain**: Real-time fraud detection under extreme class imbalance (<0.2%) and sub-millisecond latency budgets for instant payment rails (UPI / Faster Payments).
- **Tech Stack**: `TensorFlow` • `CRNN + Bahdanau Attention` • `In-Memory Graph` • `FastAPI` • `Docker` • `Streamlit`
- **Key Highlight**: **Sub-1.2 ms inference latency** (~865+ req/s throughput) achieved via compiled `@tf.function` graph tracing, multi-tier defense fusion, and dynamic payment graph mule-ring detection.

#### 3. 🔬 [Breast Cancer Sentinel 2.0](https://github.com/Paritosh8-AI/Breast-Cancer-Detection)
> **Clinical AI Diagnostic Decision Support System for Breast FNA Cytology**
- **Domain**: Minimizes fatal False Negatives in cytological evaluation of breast fine needle aspirates (FNA).
- **Tech Stack**: `Scikit-Learn` • `HistGBM + RF + MLP Ensemble` • `Platt Scaling` • `FastAPI` • `Docker` • `Streamlit`
- **Key Highlight**: Soft-voting clinical ensemble reaching **99.67% ROC-AUC** and **95.24% sensitivity**, equipped with Z-score biomarker explainability (XAI) and a medical-grade SOC dashboard.
